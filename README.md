# Coursewise

Coursewise is a mobile-first academic companion designed as a competitor to Canvas Student. It helps students understand grades and instructor feedback, plan work before deadlines, connect those plans to their calendars, and continue complex work on a laptop.

## Live prototype

The GitHub Pages link will be added here after deployment.

## Run locally

No build tools or dependencies are required. Open `index.html` in a browser, or serve the folder with any static web server.

## Test flows

- Today → Research synthesis → Review feedback → Open on laptop
- Today → Prototype critique → Edit date/time/duration/calendar → Save schedule
- Plan → Open every listed work item
- Grades → Open every listed grade
- Bottom navigation → Today, Plan, Grades, and Courses

## Research basis

Four student interviews indicated that students primarily use Canvas Mobile to monitor deadlines and grades, struggle to locate assignment feedback, use external planning tools, and move to desktop when work requires action. Coursewise focuses on understanding results, planning time, and handing work off between devices.
